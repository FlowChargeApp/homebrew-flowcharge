# homebrew-flowcharge

A personal Homebrew tap for FlowCharge.

## Install

```sh
brew install <owner>/flowcharge/flowcharge
```

Use this fully qualified one-line form. Homebrew 6.0.0 and later ask for explicit
trust before they run a formula from a tap that is not official. The qualified form
grants that trust for this one formula.

## The formula is generated

`Formula/flowcharge.rb` is generated by `.github/scripts/bump-formula.mjs` in the
private FlowCharge source repository. Do not edit it by hand. The next bump
overwrites all hand edits.

## Windows and Linux arm64

Homebrew does not run natively on Windows, and no Linux arm64 binary is built.
Windows and Linux arm64 users get the binary from the Releases page instead.
